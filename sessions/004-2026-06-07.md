## Schema audit findings (done in plan mode)

The construction feature hinged on one question — does the schema support progressive
(slot-by-slot) reveal? **Yes, fully.**

- **Canonical fragment location:** *option-level* — `rounds[i].options[correctIndex].fragments.{python,java}`.
- **Per-option fragments:** **every** option (all 4) carries `fragments.{python,java}`, not
  just the correct one. → The brief's premise that "distractor fragments don't exist" was
  **wrong**; generous mode is already unblocked at the schema level (see Surprises).
- **Scaffold/template:** `scaffolds.{python,java}` are full programs with five
  `{{state}}…{{output}}` markers (one each, validated). `canonicalSolutions.{python,java}`
  is the composed program, and the validator's compose invariant guarantees rendering the
  scaffold with the five *correct* fragments equals it byte-for-byte.

**Rendering mode implemented: PROGRESSIVE.** `lib/build-code.ts` fills stages
`[0, completedThroughRound)` with their correct fragment and the rest with a placeholder
comment; at `completedThroughRound = 5` the output *is* `canonicalSolutions[language]`
(verified `=== true`).

## Surprises

1. **Generous mode is already unblocked.** Every option carries both-language fragments, so a
   future "fill wrong slots with the user's actual pick" mode needs **no schema change** —
   only `Answer.chosen` (already stored) + a tweak to `buildConstructedCode`.
2. **Headless screenshot viewport artifact.** Edge `--headless --window-size=390,…` clipped the
   right edge on **both** pages — but the home table has `overflow-hidden` (can't widen the page)
   and the responsive `viewport` meta + breakpoints work (2-col→1-col stacks correctly). So it's
   a capture artifact, **not** a real mobile break; the stopping rule was not tripped. New
   components use mobile-safe patterns (`overflow-x-auto`, `min-w-0` + `break-words`).
3. **Inline `{{output}}` placeholder reads oddly.** The output marker sits after `return `, so an
   unfilled output renders as `return # … output — round 5` (py) / `return // …;` (java). Fine as
   a visual placeholder; only ever shows before the final round.
